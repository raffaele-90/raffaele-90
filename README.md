# **Hi, I'm Raffaele Schiavone**

I got my hands on my first PC in 2002 and started building them in 2005. Over the years, my curiosity has pushed me to delve deeper into optimization and modding, leading me to design and build custom liquid cooling systems since 2017. My digital ecosystem is based on Arch Linux (for everyday use) and Debian (on my server): I use free operating systems, free from corporate logic.

In real life, I work in chemistry.

🛠️ Current Projects

Aquacontrol: a control suite for the Aquacomputer ecosystem, currently only supporting the Aquaero 6 LT and Farbwerk 360 as RGB headers, developed as an alternative to Aquasuite (available exclusively for Microsoft Windows). This project is requiring a lot of effort and is currently under development.

🔮 Future Developments

I plan to develop fan management software for GPD devices on Linux. I'd also like to develop software to control the RME ADI-2 FS DAC, which doesn't have native parameter management software on Linux, forcing the user to navigate the device's complex menu using physical buttons. I also plan to write some utilities for managing Arch and, in general, to make hardware that doesn't work on Linux because the manufacturers don't support it work. Since I don't like leaving things unfinished, I'm currently focusing all my efforts on AquaControl, which has turned out to be much more complex and demanding than I initially thought, because the official suite is a monster developed over 10 years ago, full of complex features that I've tried to implement, at least in part.

⚠️ Warning

The code I publish is open source, readable by anyone, maintained independently with the utmost seriousness, and offered FREE, despite the cost of working days, bug fixes, feature testing, and actual costs. Constructive criticism for improvement is welcome, but other criticism is not accepted, especially from those who don't collaborate on the project and don't write alternative software that offers the same features.
It would be very helpful if you could report any problems or bugs related to the software I publish on the project pages.
