## **Hi, I'm Raffaele Schiavone

I've been tinkering with PCs since 2002 and building custom rigs since 2005. Over the years, my curiosity has driven me deeper into optimization and modding, leading me to design and build custom liquid cooling loops since 2017. My digital ecosystem relies on Arch Linux (for daily use) and Debian (on my server): I choose transparent, flexible operating systems, free from proprietary logic and telemetry.

In real life, I am a chemistry student, not a professional programmer. For me, coding isn't a passion in itself, but a means to achieve a result. I develop my projects by working closely with artificial intelligence tools: I provide the ideas, the system logic, the hardware reverse-engineering, and hours of testing; the AI helps me translate all of this into functional code.

🛠️ Current Projects

OpenAquaero: A control suite for the Aquacomputer Aquaero 6 LT, built as an alternative to Aquasuite (which is exclusively released for Microsoft Windows). Built from scratch, this project took a lot of effort and logical reasoning to finally allow me to use this controller without having to rely on a Windows/Linux dual boot or virtual machines just to change a few parameters.

GPDSense (Work in Progress, unreleased): A utility dedicated to fan curve management and monitoring for GPD devices (currently in development on my GPD Pocket 4).

🔮 Future Developments

Chemistry Tools: In the future, I plan to combine my academic background with programming to create useful software tools specifically for this field.

Other Utilities: As an owner of other hardware lacking native Linux software, my goal is to build those tools over time. For example, as a user of the RME ADI-2 DAC FS—high-end hardware for Hi-Fi audio listening—I miss having native software (like the one RME provides for Windows and macOS) to manage the device directly from my operating system.
